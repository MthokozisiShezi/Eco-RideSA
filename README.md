## Project Overview

EcoRide SA is an imaginary electric scooter rental company based in Randburg, Gauteng. The company was started in January 2025 by two engineering students from the University of Johannesburg.

The company started with 20 scooters and currently has 80 scooters. The stations are located at Randburg CBD, Cresta and UJ Kingsway Campus.

The website allows customers to view the available scooters, check prices, read safety information, find scooter stations and send an enquiry.

## Website Goals

* *Inform:* Provide information about EcoRide SA, the scooters, prices and safety.
* *Engage:* Allow visitors to submit an enquiry form.
* *Convert:* Give visitors ways to become customers through the enquiry form, email and phone.
* *Be found:* Make the website easy to find when searching for scooter rentals around Randburg.

### Target Audience

The website is aimed mainly at students and young professionals between 18 and 35 years old in Gauteng, especially around UJ, Wits, Randburg, Sandton and Fourways.

## Styling and Responsive Design

The website uses one external CSS file:

text
css/style.css


The stylesheet is linked to all the HTML pages.

The CSS includes:

* CSS reset
* Base fonts and colours
* Heading styles
* CSS Grid layouts
* Flexbox layouts
* Hover effects
* Focus effects
* Active states
* Responsive media queries

### Screen Sizes

* *Desktop:* above 900px
* *Tablet:* 900px and below
* *Mobile:* 700px and below

rem, em and % are used for different sizes, spacing and widths.

The <picture> element and srcset are used for responsive images. The mobile navigation menu is controlled using js/script.js.
